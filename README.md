An optimized repository of **Java Data Structures & Algorithms** emphasizing Java Collections Framework (HashMap, Map), two-pointer array manipulations, and sliding window substring problems.

---

## 📂 Core Implementations

### 1. Hash Maps & Frequency Analysis (src/Map/)
- **MapWordsOccur.java**: Word frequency distribution and text histogram analysis.
- **Duplicate.java**: (N)$ duplicate detection via hash hashing.
- **MapArrayPairs.java**: Two-sum pair matching with hash maps.

### 2. Array Manipulations & In-Place Algorithms (src/Array/)
- **RotateArray.java**: Cyclic array rotation in-place without auxiliary memory.
- **Zeromove.java**: Partitioning zero elements to array boundaries (Move Zeroes pattern).
- **Occur.java**: Element frequency and appearance tracking.

### 3. Sliding Window & Substrings (src/Arrays/SubString/)
- **SmallestSubstring.java**: Sliding window minimum window substring discovery.
